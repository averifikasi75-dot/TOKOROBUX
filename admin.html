Foto testimoni ditaruh di folder testi. Kalau websitemu diupload dengan cara seret folder ke Netlify, pilih foto-fotonya di sini untuk membuat daftar.json, lalu taruh file itu di folder testi sebelum upload. Kalau pakai GitHub, bagian ini tidak perlu karena daftarnya dibuat otomatis.

Cara memasang nomor baru di Netlify

  1. Unduh config.js lewat tombol di atas.
  2. Ganti file config.js lama di folder website kamu dengan yang baru.
  3. Buka Netlify, masuk ke situs kamu, tab Deploys, lalu seret (drag & drop) seluruh folder website ke area upload.
  4. Tunggu beberapa detik sampai statusnya Published, lalu buka websitenya dan cek nomor barunya.

Kalau websitenya terhubung ke GitHub, cukup edit config.js di GitHub. Netlify akan memperbaruinya sendiri.
